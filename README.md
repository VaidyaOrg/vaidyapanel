
# Health Management Portal - IIT Bhilai

## Overview
The Health Management Portal is a comprehensive platform designed for the health center of IIT Bhilai. It provides various features to enhance user experience and streamline medical services. The portal is deployed at [Vaidya Panel](https://vaidyapanel.vercel.app/).

## Features
- **Home Section**: Contains contact details, event calendar, and announcements.
- **Facilities Section**: Lists available medical facilities.
- **Book Appointment**: Schedule an appointment with doctors.
- **Lab Tests**: Book lab tests and view reports.
- **Events**: Stay updated on health-related events.
- **Blogs**: Read health-related articles and blogs.
- **Buy Medicines**: Order medicines directly through the portal.
- **Additional Features**: Contact doctors, manage bookings, and more.

## Getting Started
Follow these steps to set up and run the project locally:

### Prerequisites
Ensure you have the following installed:
- Node.js
- Npm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/VaidyaOrg/vaidyapanel
   cd vaidyapanel
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run start
   ```

## Important Notes
- **Enable Third-Party Cookies**: Please allow third-party cookies before using this website for a seamless experience.

The portal is deployed at [Vaidya Panel](https://vaidyapanel.vercel.app/). Ensure all environment variables are properly configured before deploying your own instance.
